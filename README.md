# Assessment Submission for Module Computional Theory

This repository contains my submission for the module Computional Theory.
The project is written in a single Jupyter notebook in Python.
Everything needed to run the notebook is included in this repository.

## Quick Look

- You can click on [problems.ipynb] in the repository and GitHub will display it in static format.
- You can view the notbook in [Google Colab](https://colab.research.google.com/).
- You can view the notebook using [nbviewer](https://nbviewer.org/) also.

## Running the Notebook

In order to run `problems.ipnb` you can follow these steps:
1.Clone the repository using [git](https://git-scm.com/).
2.Ensure you have [Python](https://www.python.org/) installed. An easy way to get Python is to use [uv](https://docs.astral.sh/uv/) or [Anaconda](https://anaconda.org/anaconda/python).

## Dependencies

The notbook depends on the [numpy](https://numpy.org/) package and the [matplotlib] package.
